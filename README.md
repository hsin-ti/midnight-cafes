# 🌙 深夜咖啡廳精選指南 (Midnight Cafes Guide)

專為夜貓子打造的不限時、營業至凌晨的深夜咖啡廳口袋名單與精選指南。

## 📁 專案架構 (File Structure)
* `index.html`：網站首頁，提供卡片式總覽與各店家快速導覽。
* `AGENTS.md`：AI 協作與維護規範（專案憲法）。
* `cafes/`：存放所有個別咖啡廳詳細頁面的資料夾。
  * `*.html`：各店家的詳細資訊頁面（營業時間、低消、插座評比、地址等）。
  * `images/`：存放各咖啡廳的現場實景照片。

## 🚀 如何預覽與部署 (Preview & Deployment)
* **本機預覽**：使用純靜態 HTML/CSS 架構，可直接於本機瀏覽器開啟 `index.html`。
* **線上瀏覽**：本專案已部署至 **GitHub Pages**，可透過下方網頁連結直接訪問。
